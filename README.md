# Reroncening Pakurmatan

> **Repositori ini masih dalam tahap penyusunan.**
>
> Untuk sementara, silakan kunjungi repositori sebelumnya untuk melihat karya dan dokumentasi yang telah tersedia:
>
> **[Geguritan](https://github.com/sayektiandra/geguritan)**
>
> ---
>
> **Workspace**
>
> Kunjungi direktori `workspace/` untuk melihat guratan, catatan, rancangan, dan proses kreatif dalam pengembangan karya.
>
> **Penetapan Karya**
>
> Setiap karya yang dipersiapkan untuk diterbitkan terlebih dahulu disusun dan ditetapkan dalam `workspace/draft/`. Setelah melalui pemeriksaan dan ditetapkan sebagai kanonik, salinannya ditempatkan di `karya/`.
>
> Pemberitahuan ini akan diperbarui setelah penyusunan dan penataan repositori selesai.
